
# Student Management System

A web-based Student Management System built using Python, Flask, SQLite, HTML and CSS.

## Features

- Add and register new students
- View all registered students
- Search students by name
- Edit student information
- Delete student records
- Validate email addresses
- Validate 10-digit Indian mobile numbers
- Prevent duplicate email registrations
- Responsive and professional dashboard

## Technologies Used

- Python
- Flask
- SQLite
- HTML5
- CSS3
- Git and GitHub

## How to Run the Project

1. Clone this repository:

   git clone YOUR_REPOSITORY_URL

2. Open the project folder.

3. Create and activate a virtual environment:

   python -m venv venv

4. Install Flask:

   pip install flask

5. Run the application:

   python app.py

6. Open your browser and visit:

   http://127.0.0.1:5000/

## Project Purpose

This project was developed to practice Python web development, database operations, CRUD functionality, form validation and frontend design.
